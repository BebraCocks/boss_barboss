# boss_barboss — мультики по идее

Короткие вертикальные мультфильмы (1080×1920) по вашей идее и вашим картинкам.

## Как пользоваться (с телефона)
1. Откройте сессию Claude с этим репозиторием.
2. Напишите идею обычными словами. Например: «Он идёт по парку и пинает камни, 5 секунд».
3. Скиньте картинки: персонажа, фон, примеры того, что нравится. Персонажа Claude сам вырежет
   с картинки и соберёт ему скелет.
4. Claude пришлёт **хайлайты**: скриншоты главных сцен, иногда черновое видео без звука.
5. Ответьте, что поправить или добавить. Или напишите **«забирай»**.
6. После «забирай» Claude сделает финальное видео со звуком и пришлёт его в чат.

Всё собирается на сервере (three.js), Blender не нужен. Готовые видео лежат в `projects/<имя>/final/`.
